# BeatCraft v2 — 魔王關 + 雙人對戰 + 限動分享

30秒一局的節奏小遊戲，現在有魔王關會飄、可以雙人PK、結算直接產限動圖。

## 玩法
- 單人: D F J K 或點擊對應顏色
- 雙人: 左邊 D F 藍隊 / 右邊 J K 粉隊
- Lv4 魔王關 160BPM 音符會左右飄

## 本地測試
直接雙擊 index.html 就能跑

## 部署到 GitHub Pages
1. GitHub 建新 repo: beatcraft (Public)
2. 上傳 index.html + README.md
3. Settings > Pages > Source: Deploy from a branch > main / root > Save
4. 等1-2分鐘，重新整理就會看到網址

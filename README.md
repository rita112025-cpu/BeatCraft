# BeatCraft v3 — 12 道節奏挑戰

30 秒一局的繁體中文節奏遊戲，支援鍵盤與觸控、單人挑戰、雙人對戰及成績分享。

## v3 新增功能

- **12 道關卡**：新增森林迴響、霓虹街道、極光之舞、熔岩疾走、星河風暴、終極節奏王，最高 240 BPM。
- **進度儲存**：單人標準速度會保存最高分與星星；獲得 1 星即可解鎖下一關。
- **練習模式**：無限生命，開放所有關卡，不影響正式紀錄。
- **變速挑戰**：0.75×、1×、1.25×，非標準速度不計入正式紀錄。
- **暫停與倒數**：空白鍵或暫停按鈕操作；切換視窗自動暫停，繼續時倒數 3 秒。
- **公平的雙人譜面**：兩隊每拍各收到一顆音符。
- **判定修正**：同一顆音符只能計分或扣血一次，忽略鍵盤長按產生的重複事件。
- **成績回饋**：顯示命中率，保留 1080×1920 限動圖片下載與系統分享；分享文字使用實際網址。

## 玩法

- 單人：D、F、J、K，或點擊畫面下方對應按鍵。
- 雙人：藍隊 D、F；粉隊 J、K。
- 音符中心抵達打擊線時按下對應鍵；魔王關音符會左右飄移。
- 星星門檻：超過 400 / 1200 / 2200 分可得 1 / 2 / 3 星。
- 雙人、練習與變速成績不會解鎖單人關卡。

進度僅存於目前瀏覽器的 localStorage，沒有跨裝置同步；清除網站資料會移除紀錄。瀏覽器封鎖儲存時仍可遊玩，但無法保留進度。

## 本地執行

現在使用 JavaScript 模組，請透過 HTTP 伺服器開啟：

```sh
python3 -m http.server 8000
```

開啟 http://localhost:8000。核心遊戲不需外部程式庫連線；Google Fonts 無法載入時會使用系統字型。

## 測試

需 Node.js 20 以上，不需安裝套件：

```sh
npm test
```

測試涵蓋 12 關設定、存檔與錯誤復原、解鎖與最高分、單雙人譜面，以及選關、練習、倒數、暫停和返回選關的元件狀態流程。元件測試使用模擬 hooks，無法取代真實瀏覽器的畫面、音訊與觸控實測。

## 檔案

- `index.html`：頁面與現有樣式。
- `game.js`：從原始壓縮版抽出的 React 遊戲元件與互動。
- `progress.js`：關卡設定、進度規則、存檔與固定譜面。
- `runtime.js`：保留原版內嵌的 React 執行環境，無建置流程。
- `tests/`：無外部依賴的自動化測試。
